# Multiple documents and Open Recent: requirements

## R1 Several files open at once
- R1.1 Each PDF or image opens in its own window, as in Preview, with its own
  map selection, scale override and page setup.
- R1.2 Opening a file that is already open brings its window forward.
- R1.3 File ▸ Open… accepts several files; Finder "Open With", the Dock and
  drops onto a window open files the same way.
- R1.4 The empty window shown at launch closes once a file is open.
- R1.5 File-menu commands (Export, Page Setup, Print) act on the frontmost
  window.

## R2 Open Recent
- R2.1 File ▸ Open Recent lists recently opened files, newest first, and
  opens one when chosen.
- R2.2 Clear Menu empties the list.
- R2.3 The list is the system's recent-documents list, so the Dock menu shows
  the same files.
