# Multiple documents and Open Recent: requirements

## R1 Several files open at once
- R1.1 Each PDF or image opens in its own window, as in Preview, with its own
  map selection, scale override and page setup.
- R1.2 Opening a file that is already open brings its window forward.
- R1.3 File ▸ Open… accepts several files; Finder "Open With", the Dock and
  drops onto a window open files the same way.
- R1.4 The empty window shown at launch closes once a file is open.
- R1.5 File-menu commands (Export, Page Setup, Print) act on the frontmost
  window.
- R1.6 A new window starts from the page setup most recently confirmed in any
  window, also after Mapsmith has been quit and opened again.

## R2 Open Recent
- R2.1 File ▸ Open Recent lists recently opened files, newest first, and
  opens one when chosen.
- R2.2 Clear Menu empties the list.
- R2.3 The list is the system's recent-documents list, so the Dock menu shows
  the same files.

## R3 Dropping images from other apps
- R3.1 An image dragged out of another app as image data rather than as a
  file (for example a map dragged from Pluck) can be dropped on a window and
  opens like any other file.
- R3.2 When a drag carries both a file and image data, the file is used.

## R4 New from Clipboard
- R4.1 File ▸ New from Clipboard (⌥⌘N), on the Mac and on the iPad with a keyboard, opens the map on the
  clipboard: an image copied in another app (such as Pluck, a browser or Preview), a screenshot, or PDFs and
  images copied as files.
- R4.2 Copied files are opened like dropped files; copied image data opens like a dropped image, named
  "Pasted Map".
- R4.3 The command is disabled when the clipboard holds no image, PDF or file.
- R4.4 Checking the clipboard asks the user for no paste permission; only choosing the command reads it.
